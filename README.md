# 指尖小助手

面向《指尖像素城》玩家的公开静态网页，提供区服日历、全服活动、圣域赛果与指尖百科。

[资源统计器](https://detlettuce2.github.io/fingertip-assistant/?view=resources) 比较 VIP0～20 的每日资源收入与星钻支出。可从上往下拖动建筑决定优先级，取消未拥有的角色后自动生成不重复的最优进驻搭配，并保存排序和角色选择。默认传送阵、远古遗迹、星辰之塔、冒险者公会、空港，全部角色可用时依次为 67%、67%、66%、64%、66%；把星辰之塔移至第一位可达到 67%。默认高战口径，只计金币／经验副本并排除魔王币。首页突出收益与搭配，详细条件折叠；支持加速、终身卡、建筑等级、冒险进度、收取频率、额外收入、全资源切换与 CSV 导出。计算条件与覆盖范围见 [资源统计器说明](docs/resource-calculator.md)。

[指尖百科](https://detlettuce2.github.io/fingertip-assistant/?view=encyclopedia) 下提供物品、角色、符文、魔宠、圣物、兽印六个图鉴入口。角色展示阵营、定位、基础技能及进阶／升星效果；符文展示类型与各星级效果；魔宠和圣物展示技能与成长说明；兽印可筛选稀有词条。支持名称／技能效果搜索、分类筛选、分页和条目分享链接。分类图鉴资料版本为 2026-09-30，仅发布整理后的静态展示数据，沿用现有公开图片。

新增 [兽印洗炼模拟器](https://detlettuce2.github.io/fingertip-assistant/?view=seal)：支持三种可洗炼兽印、词条预览、单次与连续洗炼、减速滚轮动画、彩色约 40 次／绿色约 42 次软保底、红色 3% 模拟稀有率、稀有／心愿停手、锁定、次数和材料统计、出货记录、刷新恢复及 CSV 导出。

词条、消耗和基础分类概率来自游戏官方公示；软保底为模拟器新增规则，不代表游戏官方机制。记录仅保存在当前浏览器，不与游戏账户同步。规则和验证说明见 [兽印模拟器说明](docs/beast-seal-simulator.md)。

访问地址：<https://detlettuce2.github.io/fingertip-assistant/>

本仓库只包含浏览器直接使用的网页文件、展示数据和图片素材，不包含数据采集、协议解析或游戏资源处理工具。

兽印图鉴支持按适用魔宠筛选，通用和专属词条分栏。圣物图鉴可指定等级区间查询圣物之晶、圣物觉醒石和属性曲线。角色图鉴以 1000 级后的成长为主要入口，支持经验、金币、升阶棱晶统计、四职业曲线比较、分段增量和 CSV 导出，并补齐 18 名星痕角色的十五阶效果。计算口径见 [图鉴成长查询说明](docs/catalog-growth.md)。

圣域阵容和百科数据在发布前采用严格字段白名单，并由自动化测试检查内部标识、本地路径和回放信息。详细规则见 [公开数据脱敏规范](docs/public-data-privacy.md)。

圣域回顾支持 S14、S15 切换。S15 包含指尖／指尖像素七区、像素一区、浮空岛一区、奥术殿三区、熔火城一区、深境一区，共 448 场赛果，可查看双方当场上阵、助战和魔宠阵容；不加入出场率或胜率统计。

## 本地查看与测试

在仓库目录执行 `python -m http.server 4173`，访问 `http://localhost:4173/?view=seal`。页面需要 HTTP 服务读取 JSON，不能直接双击 HTML。

逻辑测试：Node.js 20 或以上执行 `npm test`，无需先安装依赖。

浏览器回归：执行 `npm ci`、`npx playwright install chromium`，然后运行 `npm run test:browser`。测试会自行启动临时本地服务和独立浏览器，输出截图与导出样本到已忽略的 `output/playwright/`。也可以通过 `BROWSER_EXECUTABLE` 指定本机 Chrome 路径。Playwright 仅用于开发测试，线上页面仍为无运行时依赖的静态网页。
