# 兽印洗炼模拟器

## 使用

网站导航选择「兽印洗炼」，或访问 `?view=seal`。选定雷霆虎、圣角兽或焚焰凤后，可进行单次、10 次、100 次或 1,000 次连续模拟。上下两条是滚动装饰，中间高亮部分才是本次结果，每次只结算一条。

出货的定义为配置 `r2a3re = 1`。默认遇到稀有词条停手；可在预览中搜索魔宠、效果或精确编号，并选择心愿词条，命中后也会停手。洗炼替换当前词条，但历史出货记录保留。锁定后不能继续洗炼。可跳过动画或随时停止连续洗炼；离开该功能页或将页面切到后台也会停止。

每种品质分别保留当前词条和锁定状态，累计次数、出货和精魄消耗跨品质统计。记录仅保存在当前浏览器的 `fingertip.beast-seal.v1` 存储项内，不访问游戏账号、不消耗真实道具。清除浏览器站点数据会丢失记录，因此提供带 UTF-8 BOM 的 CSV 导出。每轮最多 10,000 次，达到上限后请先导出再开启新一轮；不会静默删除旧记录。无法保存或存档损坏时会明确提示，损坏存档可下载原始备份。

## 配置依据与模拟假设

输入是用户提供的 `Config.rar`，没有运行压缩包内代码。只发布与该功能相关的展示配置；不上传整个压缩包或其他配置。

- `api/beast-seal.json` 与 `Config/beast_seal_cfg.json` 字节一致。SHA-256：`516fc7e6cfd4ee3f8651de852222fd001d4fd469fd44823dfd5ea432eb7fcd94`。
- 第 2 节：品质 6 / 7 / 8 消耗物品 250210501，分别为 6 / 12 / 20 个。仓库物品图鉴中名称为「兽印精魄」。
- 第 6 节：共 429 条词条，保留词条 ID、品质、技能类型、稀有标记、适用效果 ID 和原始描述。可洗炼的品质 6 / 7 / 8 分别有 72 / 99 / 111 条。
- `h4e5lp_cfg.json` 第 283 项说明每个兽印随机获得一个词条；第 322 项提供概率公示。
- `l4a5nguage_cfg.json` 第 212013 项为稀有词条洗炼确认，第 212017 项说明已锁定兽印不能洗炼。
- 品质入口依据明确存在的洗炼消耗配置；未用第 1 节 `max_color = 7` 排除品质 8，因为配置同时包含品质 8 的洗炼消耗和词条。这一字段的服务端用途不能由静态配置确认。

### 概率歧义

帮助配置的原始文字如下（保留原数值的百分号），每个兽印的各项合计均只有 **1%**：

| 兽印 | 原文 | 本模拟默认归一化后 |
| --- | --- | --- |
| 雷霆虎 | 通用 0.36%；专属 0.64% | 通用 36%；专属 64% |
| 圣角兽 | 通用稀有 0.0034%；通用 0.3550%；专属稀有 0.0272%；专属 0.6144% | 通用稀有 0.34%；通用 35.50%；专属稀有 2.72%；专属 61.44% |
| 焚焰凤 | 通用稀有 0.0025%；通用 0.4057%；专属稀有 0.0205%；专属 0.5713% | 通用稀有 0.25%；通用 40.57%；专属稀有 2.05%；专属 57.13% |

无法仅凭这些文字判断是展示单位错误、分组权重还是服务端另有解释，因此**不宣称还原了官方概率**。当前可复现的推演规则：

1. 只抽取与所选兽印品质相同的词条。
2. 按技能类型编号区分通用与专属（`skill_type < 1000` 为通用），这是依据数据结构做出的分组解释。
3. 先按归一化权重选择分组，再在该组内等概率抽取一个词条。雷霆虎原文没有细分稀有，因此两组均包含其原有稀有词条，不擅自套用品质 7、8 的稀有概率。
4. 每次独立随机，没有保底，不随历史次数调整概率。
5. 用户可以在「规则与概率」中修改各组权重。历史记录引用其洗炼时的概率快照，导出时保留。

未模拟装备格子、合成、真实账户余额或服务端结果。参考截图的蓝色边框、金色结果槽、绿色预览入口和橙色按钮用网页样式实现，魔宠与兽印图像复用仓库现有素材。

## 验证

- 8 项 Node 逻辑测试：配置数量、分品质词条池、消耗、概率边界、无效权重、单次结算、累计统计、锁定与容量、存档校验、CSV、十万次固定种子抽样。
- 浏览器正常流程 25 项断言：真实点击、重复点击、稀有保护、连续与手动停手、心愿、搜索、刷新恢复、历史分页、下载、跨品质统计、原有三个导航页面与手机布局。
- 浏览器异常与边界 19 项断言：零权重、恢复默认、配置加载失败重试、损坏存档保护和备份、清空确认、多页面同步、10,000 条记录保存、存储被禁用或写入失败、320 / 390 / 768 / 1440 像素布局。
- CSV 下载验证包含 103 条数据行及 BOM；异常存档导出验证原样保留。

测试代码位于 `tests/`，可重复执行。测试使用独立浏览器，测试记录不会进入正式站点。实际游戏服务器概率及游戏内洗炼未验证，也不在本模拟器的连接范围内。
