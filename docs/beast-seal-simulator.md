# 兽印洗炼模拟器

## 使用

网站导航选择「兽印洗炼」，或访问 `?view=seal`。选定雷霆虎、圣角兽或焚焰凤后，可进行单次、10 次、100 次或 1,000 次连续模拟。中间高亮部分才是本次实际结果，每次只结算一条词条。

通常上下两条仅作滚动展示。软保底触发时，界面会同时展示三条稀有词条：中间是本次获得的词条，上下是另外两条稀有词条，不会作为额外奖励计入记录。

默认遇到稀有词条停手；可在预览中搜索魔宠、效果或精确编号，并选择心愿词条，命中后也会停手。洗炼会替换当前词条，但历史出货记录保留。锁定后不能继续洗炼。

洗炼动画采用纵向词条滚轮，由快速滚动逐渐减速，最终准确停靠到本次结果；单次动画约 1.4 秒，连续洗炼每次约 0.76 秒。可跳过动画，系统开启「减少动态效果」时也会自动跳过。随时停止、离开该功能页、切到后台或动画中改变窗口尺寸都会取消当前未完成的洗炼，不增加次数或材料消耗；此前完成的记录仍会保留。

每种兽印分别保留当前词条、锁定状态和连续未出稀有次数，累计洗炼、出货和精魄消耗跨三种兽印统计。记录仅保存在当前浏览器的 `fingertip.beast-seal.v1` 存储项内，不访问游戏账号、不消耗真实道具。清除浏览器站点数据会丢失记录，因此提供带 UTF-8 BOM 的 CSV 导出。每轮最多 10,000 次，达到上限后请先导出再开启新一轮；不会静默删除旧记录。

## 官方概率公示

兽印名称、词条、消耗、稀有标记和基础分类概率按游戏官方公示整理：

| 兽印 | 通用稀有 | 通用 | 专属稀有 | 专属 |
| --- | ---: | ---: | ---: | ---: |
| 雷霆虎 | — | 36% | — | 64% |
| 圣角兽（彩色） | 0.34% | 35.50% | 2.72% | 61.44% |
| 焚焰凤（绿色） | 0.25% | 40.57% | 2.05% | 57.13% |

每次只抽取与当前兽印相同品质的词条。通用／专属按词条类型分组；官方只公布分类概率，因此同一分类内的具体词条采用等概率抽取。雷霆虎的公示没有拆分稀有概率，本模拟按下述体验规则另行调整，不将模拟稀有率称为官方概率。

## 红色兽印稀有率调整

雷霆虎保留官方通用／专属 36%／64% 的分类比例，将稀有总概率调整为 3%：通用稀有 1.08%、通用普通 34.92%、专属稀有 1.92%、专属普通 62.08%。每个分组内的词条等概率抽取，不设置软保底。这是模拟体验调整，不代表游戏真实稀有率。旧版本在通用／专属组内直接等概率抽取，按当前词条池计算的稀有率约为 17.64%。

## 软保底规则

软保底是本模拟器新增的体验规则，不代表游戏官方存在同样机制。三种兽印分别计数，提前自然抽到稀有词条后，对应兽印的连续计数立即归零。

| 兽印 | 开始提升 | 目标位置 | 最迟出货 |
| --- | ---: | ---: | ---: |
| 圣角兽（彩色） | 连续第 38 次 | 约第 40 次 | 第 43 次 |
| 焚焰凤（绿色） | 连续第 40 次 | 约第 42 次 | 第 45 次 |

提升区间采用线性递增：彩色兽印第 38～43 次、绿色兽印第 40～45 次的额外稀有触发率依次为约 16.67%、33.33%、50%、66.67%、83.33%、100%。若额外触发未命中，该次仍按官方基础概率正常抽取。因此实际可能提前出货，也会集中在第 40 次或第 42 次附近。

触发软保底的结果会在出货记录和 CSV 中单独标记。界面显示三条稀有词条时，只有中间一条是实际结果。旧版约 20 次的彩色软保底记录会保留，新抽取统一使用新版规则；旧红色兽印记录也不会被删除或重算。

## 验证

- Node 逻辑测试覆盖官方分类概率边界、红色稀有率调整、彩色和绿色软保底曲线、最迟出货、跨兽印独立计数、单次结算、累计统计、锁定与容量、新旧存档校验、CSV 和固定种子抽样。
- UI 控制器测试使用 DOM／动画替身，覆盖滚轮帧、随机数隔离、完成后结算、重复点击、手动／后台／离页／尺寸变化取消、多页面同步、动画异常和减少动态效果；不替代浏览器视觉验证。
- 浏览器回归覆盖真实点击、重复点击、稀有保护、三稀有同屏、连续与手动停手、心愿、搜索、刷新恢复、历史分页、下载、跨兽印统计及手机布局。
- 滚轮浏览器脚本覆盖真实位移、减速、最终帧对齐、三稀有停靠、不同屏宽与减少动态效果。执行 `npm ci`、`npx playwright install chromium` 后运行 `npm run test:browser`；截图保存在 `output/playwright/`。
- 异常与边界流程覆盖数据加载失败重试、损坏存档保护和备份、清空确认、多页面同步、10,000 条记录保存、存储被禁用或写入失败，以及 320 / 390 / 768 / 1440 像素布局。

测试代码位于 `tests/`，可重复执行。测试使用独立浏览器，测试记录不会进入正式站点；模拟器也不会连接实际游戏服务器。
